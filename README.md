# 🎬 Movie Recommendation System

An NLP-driven Content-Based Movie Recommendation System that suggests similar movies based on metadata feature engineering and cosine similarity.

---

##  Project Overview

This project builds a content-based recommendation engine using movie metadata such as genres, keywords, cast, crew, and overview.  

The system processes textual data, converts it into numerical vectors using CountVectorizer, and calculates cosine similarity to recommend the top 5 most similar movies.

---

##  Tech Stack

- Python
- Pandas & NumPy
- Scikit-learn
- NLTK (Stemming)
- CountVectorizer
- Cosine Similarity
- Jupyter Notebook

---

##  Dataset

- TMDB Movie Dataset  
- Contains movie metadata including genres, cast, crew, keywords, and overview.

---

##  Project Workflow

1. Data Cleaning & Preprocessing  
2. Feature Engineering (Combining multiple text features)  
3. Text Normalization using Stemming  
4. Vectorization using CountVectorizer  
5. Similarity Matrix Creation using Cosine Similarity  
6. Top 5 Movie Recommendation Output  

---

##  Key Features

- Content-Based Filtering implementation  
- NLP-based text feature extraction  
- Optimized similarity computation  
- Model serialization using pickle for faster reuse  

---

##  How to Run

1. Clone the repository  
2. Install required libraries  
3. Run the Jupyter Notebook  
4. Enter a movie name to get recommendations
